# 260923 **[Git 2.56과 3.0을 내다보며](<https://news.hada.io/topic?id=34124&utm_source=discord&utm_medium=bot&utm_campaign=5116>)**
- **Git 2.56은 9월 말 출시 예정**으로 이력 편집과 브랜치 관리 편의성을 높이며, 다음 버전을 Git 3.0으로 출시할지는 아직 논의 중임  
- 특정 커밋을 이력에서 제거하는 **`git history drop`**, 병합된 로컬 브랜치를 정리하는 `git branch --delete-merged`, 충돌을 해결한 파일만 스테이징하는 `git add --resolved`가 추가됨  
- Git 3.0은 새 저장소의 기본 해시를 **SHA-1에서 SHA-256으로 전환**할 예정이며, 주요 호스팅 서비스와 외부 도구의 지원이 전환 시점을 좌우함
